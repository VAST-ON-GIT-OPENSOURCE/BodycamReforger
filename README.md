# Bodycam Reforger

![Bodycam Reforger](images/preview.png)

**Bodycam-style weapon handling for Arma Reforger.** Your weapon is carried, not glued to the mouse: it sways when you turn,
walk, strafe and lean, lowers on fast turns and kicks like in BODYCAM. Camera, movement, controls, menus and all vehicles
stay 100 % Arma.

## Get the mod

**[Bodycam Reforger on the Arma Reforger Workshop](https://reforger.armaplatform.com/workshop/F26C9CD1DDF4D30E-BodycamReforger)**
(in game: Workshop → search "Bodycam Reforger" → subscribe). Servers list it like any other mod (mod ID
`F26C9CD1DDF4D30E`); players download it automatically.

## Companion program (optional, Windows)

Only if you own **BODYCAM** on Steam. Without it the mod uses its own stand-in values and Arma's recoil.

1. Download `BodycamReforger-Companion-1.0.0.zip` from **[Releases](../../releases/latest)** and unpack it (keep the folder together).
2. Start `bcr_companion.exe`, then start Arma Reforger with the mod.
3. On the first start the mod fetches the sway and recoil values and remembers them. The program quits by itself.

What it does: it reads those values from **your own** BODYCAM installation (read only, nothing in it is changed) and hands
them to the mod on this PC only (`127.0.0.1`). Nothing is sent to the internet. Log: `%LOCALAPPDATA%\BodycamReforger\companion.log`.
Windows may warn because the program is not signed: *More info → Run anyway*. To remove it, delete the folder and
`%LOCALAPPDATA%\BodycamReforger`.
